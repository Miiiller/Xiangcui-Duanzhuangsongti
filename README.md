# 香萃端庄宋体
![Image text](https://github.com/Miiiller/Xiangcui-Duanzhuangsongti/blob/main/1.png)  
香萃端庄宋体是一款采用GB2312编码的开源免费字体。字形高挑，整体修长，笔画粗细中等。笔画清健饱满，整体感观协调，视觉速度平缓。
## 为了满足更加现代、时尚的标题和正文用字，刻意拉高了重心，产生强烈的对比。这些特征使它更为简洁现代。
![Image text](https://github.com/Miiiller/Xiangcui-Duanzhuangsongti/blob/main/3.png)  
笔画细节干净利落，重心大致分布在3/8处，呈现冷静、锐利、简洁的效果。
## 不同字号的排版 
虽然重心拔高夸张，但正文和标题应用效果都很好，保持和谐的美感
